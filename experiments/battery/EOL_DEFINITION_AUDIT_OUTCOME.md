# EOL definition audit

The protocol requires alternate EOL-threshold sensitivity only when a common threshold can be recomputed from complete, consistently defined curves. The audit loaded every six-domain label file and corresponding processed cycle file. Labels are not equal to file length: label-minus-file-length ranges span large domain-specific offsets (for example, CALCE −1049 to −184 cycles and SNL −1372 to −14), while the original cycle data and preprocessing conventions differ by domain. Therefore the released numeric labels are domain-specific life annotations, not a common thresholded capacity-crossing definition that can be safely transformed after the fact.

We consequently do **not** fabricate 70/80/90% alternate labels. The authoritative result is the infeasibility audit in `batterylife_eol_definition_audit.json`; the frozen main endpoint remains unchanged.

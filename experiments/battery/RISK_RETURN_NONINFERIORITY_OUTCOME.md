# APACE-Cal 风险—收益与非劣效性审计

该审计只读取冻结的 `batterylife_asymmetric_cohort_router_v2.json`，不重新调阈值、不修改方法。

## 关键结果

| 设置 | 平均 active episode 比例 | 平均相对 MAPE 变化 | 逐电芯行平均非劣比例（1%/2%/5% margin） | 最差逐电芯相对变化 |
|---|---:|---:|---:|---:|
| H10/K3 | 50.0% | -15.01% | 84.1% / 85.9% / 89.0% | +95.1% |
| H20/K3 | 50.0% | -17.67% | 86.3% / 86.6% / 86.9% | +126.9% |
| H50/K3 | 50.0% | -17.16% | 88.4% / 88.4% / 90.9% | +106.1% |

## 解释

宏观上，三种主窗口均为 3/3 域改善、0 域退化；但逐电芯相对变化存在少量大幅退化行。因此，正文不应写成“每个电芯均不退化”，而应写成“域级宏平均无退化，并通过安全回退控制系统性负迁移风险”。

该结果也说明安全门的正确统计对象应是域/episode 层级，而非把每个 episode 或每个电芯行当成完全独立样本。后续正式论文统计应报告 cluster bootstrap 和域级非劣效性，而不是只报告逐行比例。
